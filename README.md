
1. Escribir la ruta del directorio o elegirla con **Examinar...**
2. Poner la profundidad maxima (0 = sin limite) y presionar **Analizar**. Se carga el arbol, las estadisticas y los duplicados. La barra de abajo muestra el progreso y se puede **Cancelar**.
3. Para buscar: escribir el texto y/o los filtros (extension, tamano minimo y maximo en KB, fechas en formato `dd/MM/yyyy`) y presionar **Buscar**. Los resultados salen en la pestana Busqueda; se ordenan dando clic al encabezado de la columna.
4. Para gestionar archivos: seleccionar un elemento en el arbol (o en la tabla de busqueda) y usar los botones Nueva carpeta, Nuevo archivo, Renombrar, Copiar, Mover o Eliminar. Para carpetas anidadas se escribe por ejemplo `a/b/c`.
5. **Abrir en editor** (o doble clic en un resultado) abre archivos de texto de maximo 1 MB. Se guardan con el boton Guardar.
6. **Exportar reporte** guarda las estadisticas en `.txt` o `.csv`.
7. La pestana **Bitacora** muestra el historial de operaciones.
